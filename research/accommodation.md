# 宿泊先 — 伝承千年の宿 佐勘（秋保温泉）【予約済】

- **URL**: https://www.hotel-sakan.com/
- **所在地**: 〒982-0241 宮城県仙台市太白区秋保町湯元薬師28
- **TEL**: 022-398-2233（受付 10:00〜17:00）／ FAX 022-398-2168
- **立地**: 秋保温泉の中心地。"日本三御湯"として知られる歴史ある温泉地
- **総客室数**: 173室

## 旅程に直結する実務情報

| 項目 | 内容 |
|------|------|
| チェックイン | 15:00 |
| チェックアウト | 11:00 |
| 駐車場 | 500台・1泊無料・予約不要 |
| 駐車場の運用 | 玄関前に立ち寄ると係員が案内。50m先の駐車場からは送迎あり |
| 仙台駅からのアクセス | 車で約30分（仙台城跡からは20〜30分） |
| 送迎バス | あり（11:00発・15:30発ほか）。予約定員制で公式サイトからのみ予約可・電話予約不可 |

今回はカーシェアで移動するため送迎バスは使用しない。駐車場は無料・予約不要なので、カーシェア車でもそのまま入庫できる。

## 温泉・館内設備

- 花月館1階大浴場
- 花月館地下1階大浴場 — 男女入替制（【男性】15:00〜19:00 【女性】20:00〜翌9:30）
- 名取の御湯
- 露天風呂「河原の湯」
- バリアフリー対応の貸切風呂

浴場によって男女入替の時間帯が異なるため、チェックイン時に当日の入替スケジュールを確認する。16:00チェックインなら、夕食（18:30）までの間に男性陣が花月館地下1階大浴場を使える時間帯にあたる。

## 食事

- 旬の食材を料理長の技で仕立てる会席
- 夕食のスタイルを選べるプランあり
- こだわりの朝食

## 予約内容で要確認の事項

- 部屋タイプと部屋数（5名1室か、2室に分かれるか）
- 夕食の開始時刻と会場（日程表は18:30想定）
- 朝食の提供時間帯（日程表は7:30想定。9:15出発に間に合う必要がある）
